The Document Manager (مدیریت اسناد) is the central hub of Parsanegar. From it you can create new academic documents using a guided wizard, open existing documents stored in your local workspace, archive completed work, search across all your documents, and keep everything synchronized with the Parsanegar cloud server. All documents are saved as `.docx` files in a dedicated workspace folder on your machine and are also registered on the server so you can access them from any device.

## Opening the Document Manager

In the Word ribbon, locate the **galleryDocumentsManager** dropdown in the Parsanegar tab. Click it to reveal three items:

| Gallery item | Arabic label | Purpose |
|---|---|---|
| Document Manager | مدیریت اسناد | Browse and open your documents |
| Archive | اسناد بایگانی | View archived documents |
| Create New Document | ایجاد سند جدید | Launch the creation wizard |

Click **مدیریت اسناد** to open the Document Manager panel. The panel loads your document list from the server and displays each document with its title, author, university, and last-updated date. You can also open the Document Manager at any time with the keyboard shortcut **Alt + F1**.

<Note>
  All documents are stored in the workspace directory configured in Parsanegar settings. The default path is `Documents\ShivaNegarWorkspace`. Make sure this folder exists and is accessible before creating or opening documents.
</Note>

## Creating a New Document

Parsanegar creates academic documents through a six-step wizard. Click **ایجاد سند جدید** from the gallery dropdown to begin. Each step must be completed before moving to the next.

<Steps>

  <Step title="Step 1 — Choose a Bismillah Style">
    The first slide lets you select the *Besmellah* (بسم‌الله) text and its calligraphic font for the opening page of your document. Three font styles are available (Besmellah 1, 2, and 3). Select the style from the font type dropdown, then choose your preferred phrase from the list. A preview updates live so you can confirm your choice before proceeding.
  </Step>

  <Step title="Step 2 — Set Document Type, Template, and Name">
    Choose the **document type** that matches your academic work:

    | Value | Persian label | Description |
    |---|---|---|
    | `SchoolResearch` (3) | تحقیق درسی | School research, special topic, or internship report |
    | `Project` (0) | پروژه | Undergraduate or postgraduate project |
    | `Thesis` (1) | پایان‌نامه | Master's thesis |
    | `Dissertation` (2) | رساله | Doctoral dissertation |

    Then choose a **template type**:

    | Value | Persian label | Description |
    |---|---|---|
    | `UniversityTemplate` (1) | قالب دانشگاهی | Official university-issued formatting |
    | `StudentTemplate` (2) | قالب دانش‌آموزی | Student-configured layout; not yet selectable in the wizard |
    | `OfficeTemplate` (3) | قالب گزارش اداری | General office report format; not yet selectable in the wizard |
    | `Nothing` (-1) | صفحه خالی | Blank document with no pre-built sections |

    Finally, enter a **document name**. The name must be unique within your workspace — Parsanegar checks the server to prevent duplicates and validates that the name contains no reserved characters. Your package entitlement is also verified at this step; an invalid or expired package will block document creation.
  </Step>

  <Step title="Step 3 — Select University and Academic Details">
    Choose the **university** from the dropdown. The list of available departments updates automatically based on the selected university. Fill in:

    - Faculty / Department (دانشکده) — select from the pre-populated list or choose *Other* to enter a custom name in both Persian and English
    - Group / Division (گروه) — similarly selectable or custom
    - Field of study (رشته تحصیلی) — in both Persian and English
    - Area of specialization (گرایش تحصیلی) — optional; both languages required if entered
    - Academic degree (مقطع تحصیلی) — the options adapt to the document type selected in Step 2
  </Step>

  <Step title="Step 4 — Enter Document and Personnel Details">
    Provide the core metadata that will appear on the cover page and identity pages of the document:

    - **Title** (عنوان) — in Persian and English
    - **Author** (نگارنده / دانشجو) — in Persian and English
    - **Supervisor** (استاد راهنما) — in Persian and English; up to two lines
    - **Advisor** (استاد مشاور) — optional; both languages required if one is provided
    - **Defense date** (تاریخ دفاع) — optional; both Persian and Gregorian formats required if provided
    - **Course name** (نام درس) — only shown for *School Research* documents
  </Step>

  <Step title="Step 5 — Review and Confirm">
    A summary table displays every piece of information collected in the previous steps, organized by type, university/education, and document details. Review the data carefully. You must check the **agreement checkbox** before the *Confirm* button becomes active. Once you confirm, the creation process starts automatically and moves to Step 6.
  </Step>

  <Step title="Step 6 — Document Assembly">
    Parsanegar assembles the document on a background thread and shows a live progress indicator. The process:

    1. Copies the university template (`.dotm`) to the Microsoft Templates folder
    2. Creates a new Word document based on that template
    3. Inserts each required section (cover, abstract, table of contents, chapters, sources, etc.) in the correct order, separated by content-controlled section breaks
    4. Populates all metadata content controls (title, author, supervisor, university icon, etc.)
    5. Saves the document to `Documents\ShivaNegarWorkspace\<name>.docx`
    6. Uploads the document and its metadata to the Parsanegar server

    When the progress bar turns green and shows **"سند شما با موفقیت ایجاد شد"**, your document is ready. The wizard closes and the new document opens in Word.
  </Step>

</Steps>

## Opening Existing Documents

In the Document Manager panel, all documents that are not currently open in Word are listed, sorted by last-updated date. Click any document card to open it. Documents that are already open in Word are filtered from the list and a count is shown at the top of the panel.

<Tip>
  Use the search bar at the top of the Document Manager to filter your documents by title. The search highlights matching text inside the results. Clearing the search field restores the full list.
</Tip>

## Archiving Documents

When a document is no longer actively being edited but you want to keep it accessible, you can archive it.

- In the Document Manager list, use the archive action on a document card to move it to the archive folder. Parsanegar updates the archive flag on the server and physically moves the file to `Documents\ShivaNegarWorkspace\بایگانی\`.
- To view archived documents, click **اسناد بایگانی** from the gallery dropdown.
- From the archive view, you can restore a document back to the active list using the unarchive action on its card.

<Note>
  A document must be closed in Word before it can be archived or unarchived. If the file is locked (currently open), Parsanegar will show an error asking you to close it first.
</Note>

## Editing Document Contents

After a document has been created, you can update its metadata (title, author, supervisor, university, abstract, keywords, and more) without recreating it from scratch.

Open the target document in Word and click **ویرایش اطلاعات** (`btnChangeContents`) in the Parsanegar ribbon, or press **Alt + F2**. The Edit Contents panel loads the current values from the server and populates each field for review. Change any fields and click **Confirm**. The add-in:

1. Updates every matching content control in the document
2. Saves the changes to the Word document's variables
3. Syncs the updated configuration to the Parsanegar server

## Document Sync and Updates

Parsanegar provides two separate actions for keeping your document current.

- **همرسانی سند** (`btnUploadDocument`, **Alt + U**) — uploads the current version of the open document to the Parsanegar cloud server. On the first use, it creates a new cloud backup; on subsequent uses, it syncs the local changes to the existing server copy.
- **بروزرسانی سند** (`btnUpdateDocument`, **Alt + R**) — refreshes all auto-generated content within the document: table of contents, list of figures, list of tables, cross-references, and bibliography entries. This is a local operation and does not contact the server.

Both operations work on the currently active Parsanegar document in Word.
